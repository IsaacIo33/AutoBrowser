# AutoBrowser
AutoBrowser is a Fast Web Browser created by IsaacIo33. You can download it at https://ioposts.farleyengineeredsolutions.com/auto/download.

## Building from the source code

The main code files are in ex/ but for the whole source code you need to download the whole Repo of code.

AutoBrowser is an electron application to create your own browser from the source you can download AutoBrowser and remove the contents of the resource/app folder and paste your edited files from this source code into it and run the AutoBrowser.exe program in the root AutoBrowser download folder.
