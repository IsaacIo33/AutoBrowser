<h1>CONTRIBUTING to AutoBrowser</h1>

<p>Not all Pull Requests will be accepted but that doesn't mean that all pull requests will be declined. It depends on if the Pull Request is reasonable and truly does, updates or fixes something.</p>


<p>When creating Pull requests open the pull requests on the betaVersion folder so other Pull Requests can be added and then be added to the final "ex" release in 1 larger update.</p>
